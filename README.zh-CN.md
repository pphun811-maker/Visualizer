# 音频可视化（Visualizer）

一个面向 Windows 的小型桌面音频频谱小组件，使用 Python 与 PyQt6 编写。它捕获电脑当前播放的声音（扬声器回环），对其进行 FFT，然后把结果绘制成一行频谱柱，显示在桌面上的一个无边框、半透明窗口中。如果播放器通过 Windows 媒体控件暴露播放状态，小组件还能显示曲目标题，并用专辑封面为频谱柱着色。

窗口没有任何边框——直接用鼠标拖动即可移动，程序驻留在系统托盘中。

## 功能

**音频捕获与频谱**

- 使用 [soundcard](https://github.com/bastibe/soundcard)（WASAPI 回环）以 48 kHz 捕获默认输出设备的回环流，每次读取 1024 帧。
- 将滚动的 4096 采样缓冲区通过 Hann 窗，然后做实数 FFT（`numpy.fft.rfft`）。
- 在 45 Hz 至 16 kHz 之间按对数间隔插值频谱，因此每根柱子覆盖的近似是相等的音乐音程，而不是相等的赫兹数。
- 转换为 dB，应用用户设置的低频压制（`tilt * log2(f/1000)`），归一化到 0–1，然后可选地用高斯核对相邻柱做卷积，使轮廓更柔和。
- 柱子的上升与下落速度不同（`rise_speed` / `fall_speed`），因此瞬态会迅速弹起，随后平滑衰减。
- 柱子按整数设备像素网格布局（统一的柱距、宽度和间隙），因此在任何 DPI 缩放或窗口宽度下，柱子的粗细与间距都保持均匀。

**媒体信息**

- 可见时每秒通过 `winrt` 绑定轮询一次 Windows 的 `GlobalSystemMediaTransportControlsSessionManager`（隐藏时每 3 秒一次），并在柱子下方绘制 `Artist — Title`。
- 在**跟随专辑封面**模式下，用 Pillow 解码当前曲目的缩略图，缩放到 50×50，并对饱和度与亮度都比较高的像素取平均（饱和度 > 0.3、明度 > 0.3；符合条件的像素太少时回退到整张图片）。结果作为柱子的颜色。仅在曲目变化时解码，而不是每次轮询都解码。

**窗口与交互**

- 无边框、半透明；大小和位置从 `settings.json` 恢复。拖动任意位置可移动窗口，拖动标题文字可单独调整标题位置（会保存回设置文件）。
- 鼠标悬停时显示三个按钮：最小化到托盘、置顶（切换永远置顶）、关闭。右键打开 设置 / 退出 菜单。
- 最小化会隐藏到托盘；双击托盘图标可恢复。隐藏时重绘定时器停止、FFT 流水线暂停、媒体轮询降至 3 秒，因此隐藏状态的小组件几乎不产生开销。

**设置对话框**（右键 → 设置）

- 滑块：上升速度、下落速度、灵敏度、低频压制、频谱平滑、音柱数量（32–320）、音柱间隙（0–10）。大多数设置立即生效；更改音柱数量或低频压制会重启音频线程。
- 开关：显示歌曲名；音柱使用渐变色（顶部 alpha 235 → 底部 120；关闭时使用 alpha 230 的纯色）。
- 颜色：跟随专辑封面，或使用标准颜色选择器选定的固定颜色。
- 显示模式，以及 简体中文 / English 切换。首次启动时根据系统区域设置检测语言并保存。

## 显示模式

| 设置 | 实际行为 |
| --- | --- |
| 停在桌面 | 一个普通的无边框窗口，启动时以及每次从托盘恢复时都会 `lower()` 到 Z 序底部。它并没有挂接到桌面 shell 上，因此任何覆盖该屏幕区域的窗口仍然会把它遮住。 |
| 永远置顶 | 使用 `WindowStaysOnTopHint` 构建；置顶按钮可在运行时切换，无需重启。 |
| 普通窗口 | 具有正常 Z 序的普通窗口。 |

在设置对话框中切换显示模式后，需要重启程序才能完全生效。

## 环境要求

- Windows 10/11。媒体信息部分使用 Windows Runtime API，音频捕获依赖 WASAPI 回环，因此本项目实际上仅支持 Windows——没有 Linux/macOS 代码路径。
- Python 3，以及 `requirements.txt` 中的软件包：PyQt6、soundcard、numpy、Pillow 和若干个 `winrt-*` 包。

## 说明与限制

- 渲染由 CPU 上的 `QPainter` 完成，由约 60 Hz 的定时器驱动。只有在柱子确实发生移动（差值 > 0.002）或有脏区域变化时，定时器才会触发重绘；静音期间会完全跳过 FFT。它不是游戏覆盖层，不会向其他进程注入任何内容；如果你仍希望它完全不打扰，可以最小化到托盘——那会直接停止所有工作。
- 没有音频设备选择器：小组件始终使用 `soundcard` 报告的默认扬声器。如果无法打开任何回环设备，线程会打印错误，柱子保持平直。
- 仓库仅包含源代码——没有安装程序，也没有预编译的二进制文件。使用下面的构建命令自行生成。
- 没有测试套件，也没有 CI；本项目只是一个个人桌面小玩具。

项目结构（已从单文件 visualizer.py 重构为包）：

```
visualizer/
  __main__.py           入口点（python -m visualizer）
  app.py                QApplication 启动逻辑
  config.py             设置加载/保存（settings.json）
  constants.py          共享的几何/柱子常量
  i18n.py               翻译与系统语言检测
  core/
    audio_thread.py     WASAPI 回环捕获 + FFT
    media_thread.py     Windows 媒体会话轮询
  ui/
    main_window.py      无边框透明覆盖窗口
    settings_dialog.py  设置面板
    icons.py            按钮图标绘制
Visualizer.spec         PyInstaller 构建配置
requirements.txt        运行时依赖
```

从源码运行：

```
pip install -r requirements.txt
python -m visualizer
```

构建独立程序包：

```
pyinstaller Visualizer.spec
```

设置保存在脚本旁边的 settings.json 中（打包后位于 .exe 旁边）；首次运行时创建，不受 git 跟踪。
